# Phase F0 Legacy Artifacts

The following root-level files and directories represent the Phase F0 standalone API contract, client, mock server, and validation suite:
- `types.ts`
- `src/types.ts`
- `src/client.ts`
- `src/validation.ts`
- `src/mock-server.ts`
- `tests/contract.test.ts`

These were based on the preliminary Phase F0 contract (where `clinical_image` was required and `dermoscopic_image` was optional). They are preserved for provenance and historical record, but are not used by the React application.
